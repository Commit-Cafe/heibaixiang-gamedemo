# 黑白柱 · 推箱子 PLUS 3D

一款基于 three.js 的 3D 协作解谜网页游戏（原型 Demo）。

## 玩法

- 棋盘为 12×12 格，活动区被黑白柱子铺满，石墙作为边界与隔断；
- 黑棋只能走**黑色且降下**的柱子，白棋只能走**白色且降下**的柱子；
- **空格**：切换黑白棋——切换瞬间全场黑白柱升降互换（黑升白降 ↔ 黑降白升）；柱子升起时该色棋子被锁定（闭眼站在柱顶）；
- **推柱**：朝一根升起的柱子按方向键，它与前方降下的柱子**换位**，棋子跟进一格——为对面棋子重新铺路；
- 黑白棋都站上**同色光圈**（黑环=黑棋目标，白环=白棋目标）即过关。

## 操作

| 按键 | 功能 |
|---|---|
| W A S D / 方向键 | 移动 / 推柱 |
| 空格 | 切换黑白棋（柱子升降互换） |
| R | 撤销一步 |
| Enter | 重开本关 |
| Esc | 打开菜单抽屉（设置 / 玩法公告 / 返回选关等） |
| E | 关卡编辑器 |
| 鼠标拖拽 / 滚轮 | 旋转 / 缩放视角（游玩中） |

## 运行

无需构建，二选一：

1. **直接双击** `index.html` 在浏览器打开（完全离线可玩）；
2. 或起一个本地服务器：`python -m http.server 8137`，访问 http://127.0.0.1:8137/index.html

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 游戏本体（规则引擎 / 3D 渲染 / 编辑器 / UI，单文件） |
| `three.module.js` / `three.core.js` | three.js 0.186.1 本地库（离线可玩） |
| `OrbitControls.js` | three.js 轨道控制器（视角旋转缩放） |

## 功能

- 内置 2 个教学关（BFS 验证过的最优解：8 步 / 15 步）
- 关卡编辑器（画笔绘制、可解性验证、JSON 导入导出分享）
- 关卡选择 + 通关记录（保存在浏览器本地）
- 内置 BFS 求解器（「验证可解」按钮，编辑器内可用）

## 技术栈

three.js 0.186.1 · 原生 JavaScript · 单文件零构建
